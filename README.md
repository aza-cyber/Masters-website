# Master's Tech — Website

The marketing website for **Master's Tech**, a software development & management studio
building apps, websites, and digital platforms. Built with React + Tailwind CSS.

## What's included
- React component structure (Nav, Hero, Marquee, About, Projects, Services, Process, CTA, Footer)
- Tailwind CSS for layout/typography
- Custom CSS + JS for:
  - custom cursor + ring
  - scroll-reveal via IntersectionObserver
  - nav blur/background on scroll
  - marquee animation

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
